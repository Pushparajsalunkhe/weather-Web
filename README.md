# 🌦️ Weather-Web Application

## 📌 Project Overview

Weather-Web is a web-based weather application that allows users to check real-time weather information for any city. It provides important weather details such as temperature, humidity, wind speed, and weather conditions.

The application uses a Weather API to fetch live weather data and displays the information through a simple and user-friendly interface.

## 🎯 Project Objectives

- Display real-time weather information.
- Search weather details by city name.
- Show temperature and weather conditions.
- Display humidity and wind speed.
- Provide a responsive and user-friendly interface.

## 🚀 Features

- **City Search:** Search weather information by entering a city name.
- **Live Weather Data:** Fetch current weather information using an API.
- **Temperature:** Display current temperature in Celsius.
- **Weather Conditions:** Show sunny, cloudy, rainy, and other conditions.
- **Humidity:** Display humidity percentage.
- **Wind Speed:** Display current wind speed.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Error Handling:** Displays an error message when an invalid city is entered.

## 🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive design.
- JavaScript – Application logic and API integration.
- Weather API – Fetching real-time weather information.

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd Weather-Web
```

3. Open `index.html` in your browser.

4. Enter a city name in the search box.

5. Click the search button to view weather information.

## 🔑 API Integration

This project uses a Weather API to retrieve live weather information.

**API Workflow:**

1. User enters a city name.
2. JavaScript captures the city name.
3. An API request is sent to the weather service.
4. The API returns weather data in JSON format.
5. JavaScript processes the response.
6. Weather information is displayed on the webpage.
